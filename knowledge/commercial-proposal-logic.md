# Oyi Commercial Proposal Logic

Use the locked positioning:

Oyi by Ochiga — The Operating System For Modern Buildings.

Do not frame proposals around software features alone. Structure every proposal around:

1. Client Overview
2. Current Challenges
3. Recommended Oyi Package
4. Assessment / Site Review
5. Deployment Scope
6. Integration Scope
7. Intelligence Scope
8. Subscription / Support
9. Timeline
10. Commercial Estimate
11. Next Steps

Recommended packages:

- Oyi Core: operational foundation for buildings moving away from WhatsApp, spreadsheets, radios and paper logs.
- Oyi Operations: services, utilities, reporting and daily building management.
- Oyi Infrastructure: cameras, devices, edge runtime, access control readiness, and smart-building integrations.
- Oyi Command Center: multi-site operations, executive intelligence, predictions, workflows, and portfolio command.

Use Building Review, Site Visit, Deployment Consultation, or Technical Inspection language for early-market first visits. Do not force paid Assessment language too early.

Hardware is always separate. Integrations depend on site readiness, credentials, supported systems, and technical review.
