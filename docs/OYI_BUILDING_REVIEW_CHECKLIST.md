# Oyi Building Review Checklist

## Building Profile

- Property type
- Location
- Buildings / floors / units / rooms / tenants
- Occupant categories
- Facility team
- Security team

## Operations

- Visitor process
- Maintenance process
- Communication channels
- Service/payment process
- Reporting process

## Infrastructure

- Cameras / DVR / NVR
- Access control
- Fiber / network
- Devices / sensors
- Utilities / meters

## Commercial

- Decision maker
- Budget range
- Timeline
- Preferred package
- Integration appetite

## Output

- Recommended package
- Deployment scope
- Integration risks
- Commercial estimate
- Next action
