# Oyi Commercial Playbook

## Positioning

**Oyi by Ochiga** is **The Operating System For Modern Buildings**.

Oyi is not estate software, smart home software, visitor software, facility software, or CCTV software. Those are capabilities inside the wider Building Operating System.

## Product Stack

- Consumer OS: occupant experience layer.
- Facility OS: building operations layer.
- Infrastructure OS: cameras, devices, utilities, access control, edge runtime.
- Oyi Intelligence: awareness, summaries, predictions, workflows, recommendations.

## Commercial Model

Building Review / Site Visit language comes first in early-market conversations.

Commercial structure:

1. Assessment / Building Review
2. Deployment
3. Integration
4. Intelligence
5. Subscription

## Sales Flow

Lead arrives → OMA qualifies → OSA converts → Building Review → Proposal → Commercial approval → Deployment project → Facility workspace → Customer onboarding.

## OMA Objective

Qualify opportunities using property type, size, pain points, infrastructure, budget, decision-maker status, timeline, and package fit.

## OSA Objective

Convert qualified opportunities through proposal generation, follow-up, objections, site visit recommendations, commercial approval tracking, and deployment handoff.
