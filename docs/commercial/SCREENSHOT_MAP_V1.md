# Screenshot Map V1

# Oyi by Ochiga

## The Operating System For Modern Buildings

This map identifies the screenshots required for Commercial Deck V3, proposals, website updates and sales collateral.

---

## Capture Rules

- Use real product screens with safe demo data.
- Do not expose private resident data, real phone numbers, payment data, camera credentials or security-sensitive details.
- Prefer polished states with live-looking but authorized demo data.
- Use consistent device frames for Consumer OS.
- Use desktop/browser frames for Facility OS and Office OS.
- Capture both full-screen and cropped module detail shots.

- Need consistent browser/device framing.
- Need one approved visual composite for deck cover.
