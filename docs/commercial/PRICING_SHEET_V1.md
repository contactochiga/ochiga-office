## Commercial Buckets

### Assessment / Building Review

Covers site/operations review, workflow mapping, user structure, infrastructure readiness, risk assessment and package recommendation.

### Deployment

Covers platform setup, estate/building setup, user onboarding, module configuration, training and go-live support.

### Integration

Covers cameras, DVR/NVR, access control, devices, sensors, smart meters, utilities, third-party systems and edge runtime work where supported.

### Subscription

Covers cloud services, Consumer OS, Facility OS, Office/Command surfaces where included, Intelligence services, updates and ongoing platform access.

### Support

Covers support retainers, managed operations, premium support, administrator assistance and expansion planning.

## Pricing Notes

- Hardware is always separate.
- Integration depends on site readiness, credentials, network access, supported equipment and technical review.
- Enterprise/government deployments require custom commercial terms.
- Subscription pricing may vary with operational scale, support level, data volume and integration complexity.
- Pilot discounts should be exchanged for reference rights, implementation cooperation and agreed success metrics.
