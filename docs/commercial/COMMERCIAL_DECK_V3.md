# Commercial Deck V3

# Oyi by Ochiga

## Positioning

**Oyi by Ochiga**
**The Operating System For Modern Buildings**

This deck is customer-facing. It is designed for estate developers, commercial building owners, hotels, campuses, government facilities, infrastructure operators and smart-building partners.

Use the deck to sell a Building Review, not to overwhelm the prospect with every module.

---

## Slide 1: Cover

**Title:** Oyi by Ochiga
**Subtitle:** The Operating System For Modern Buildings

**Body copy:**
A unified platform for occupants, operators, infrastructure, services and intelligence.

**Visual direction:**
Dark premium cover. One hero product composite: Consumer OS phone, Facility OS dashboard and infrastructure/camera/edge node motif.

**Screenshot recommendation:**
Composite using Consumer Home, Facility Overview and Office/Infrastructure command visuals.

**Presenter notes:**
Open with the category. Do not call Oyi an estate app. Say: "Most buildings have tools. Very few have an operating system. Oyi is built to become that operating layer."

---

## Slide 2: The Problem

**Title:** Buildings Are Operated Through Disconnected Tools

**Subtitle:** People, infrastructure and operations rarely work from one shared system.

**Body copy:**
- Occupants use WhatsApp groups.
- Facility teams use spreadsheets and manual logs.
- Security uses radios and standalone visitor books.
- Maintenance requests move through calls and paper trails.
- Cameras, utilities, devices and access systems operate separately.
- Management lacks live operational visibility.

**Visual direction:**
Fragmented systems diagram. Use small cards for WhatsApp, spreadsheets, CCTV, access, maintenance, utilities, radios and paper logs.

**Screenshot recommendation:**
No product screenshot. Use a clean problem diagram.

**Presenter notes:**
Make this feel familiar. The pain is not lack of software. The pain is fragmented operation.

## Slide 3: Buildings Need An Operating System

**Title:** Buildings Need An Operating System

Modern buildings need a shared layer that connects occupants, operators, infrastructure, services, data and intelligence.
